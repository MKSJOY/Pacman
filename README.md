# Pacman

This project is a simple implementation of the classic Pacman game using Java Swing for the graphical user interface. The game window features a custom board where the Pacman game is played. The program initializes the game board, sets up the main window with appropriate dimensions and title, and includes background music to enhance the user experience. The project demonstrates the basics of Java GUI development, event handling, and multimedia integration. It's a beginner-friendly project that introduces fundamental concepts in game development using Java.
